# Sjekklister – Isokor Hytteservice

*Pre Luka do mobilu. Po každej návšteve: odfajkni + 3–6 fotiek → pošli agentovi / majiteľovi.*

## 🍂 Høstlukking
- [ ] Bilde av hytta utenfra ved ankomst
- [ ] Hovedkran stengt (bilde)
- [ ] Vann tømt: kraner åpne, toalett tømt/frostvæske i vannlås, varmtvannsbereder etter eierens ønske
- [ ] Varme på frostsikring – termostat ___ °C (bilde)
- [ ] Mat ut, kjøleskap tømt, vasket og stående på gløtt
- [ ] Musesikring (feller/åte etter avtale, åpninger tettet)
- [ ] Hagemøbler, puter, griller inn
- [ ] Takrenner og nedløp renset
- [ ] Tak, piper, dører, vinduer, låser kontrollert
- [ ] Strøm: unødvendige kurser av etter avtale
- [ ] Bilder: inne (stue, kjøkken, bad), termometer, hovedkran, ute (alle sider)
- [ ] Låst, nøkkel tilbake i nøkkelboks / hos oss

## ❄️ Vintertilsyn (hver 12.–13. dag)
- [ ] Dato og klokkeslett notert
- [ ] Inne-temperatur ___ °C (bilde av termometer)
- [ ] Hovedkran fortsatt stengt
- [ ] Ingen tegn på lekkasje (gulv, under vask, rundt toalett, bereder)
- [ ] Ingen spor etter mus / skadedyr
- [ ] Ingen fukt eller vond lukt
- [ ] Tak: snømengde ca. ___ cm · skader? (bilde)
- [ ] Dører, vinduer, låser hele
- [ ] Sensor/alarm (hvis eieren har): sett på den og ta bilde – vi monterer ikke og svarer ikke for funksjonen
- [ ] Takrenner, trær og omgivelser etter storm
- [ ] 3–6 bilder · avvik meldt eier samme dag

## 🌱 Våråpning
- [ ] Bilde ved ankomst (inne og ute)
- [ ] Hovedkran på – kontroll av lekkasjer ved alle tappesteder, bereder
- [ ] Lufting
- [ ] Lett rengjøring (støv, gulv, kjøkken, bad)
- [ ] Rust- og manganflekker på toalett/badekar (Isokor)
- [ ] Vinduer
- [ ] Terrasse vasket, grønske fjernet (Isokor)
- [ ] Impregnering (hvis bestilt)
- [ ] Hagemøbler ut
- [ ] Bilder når hytta er klar

## Pasce
- Hranica 14 dní: plánuj **12–13 dní**; nikdy nie viac ako 14 medzi dvoma návštevami.
- Sviatky: ~20. 12. a ~2. 1.
- Kľúče nikdy neoznačovať adresou — len kód (H01, H02…), zoznam kódov drží agent v pamäti mimo kľúčov.
