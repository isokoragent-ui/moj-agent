# Marketing — rozcestník

*Plány a kampane už existujú inde — tu je len mapa, aby sa nič neduplikovalo.
Čo sa reálne urobilo, sa zapisuje ako `aktivita` do `../zaznamy/` a ukáže sa v raportoch.*

| Čo | Kde |
|---|---|
| Plán firmy, ciele | `02_PRACA/PLAN.md`, `02_PRACA/PROJEKTY.md` |
| Kampane | `02_PRACA/KAMPAN_*.md` |
| Príspevky na sociálne siete (postup) | `07_SCHEMY/PRISPEVOK_SOCIALNE_SIETE.md` |
| Nedeľný e-mail | `07_SCHEMY/NEDELNY_EMAIL.md` |
| Grafika | `02_PRACA/grafika/` |
| Hytteservice | `02_PRACA/hytteservice/` |
| Analýzy (e-shop, ceny, trh, SEO) | `02_PRACA/ESHOP_ANALYZA.md`, `ANALYZA_*.md`, `SEO_ANALYZA_2026-10.md` |

## Týždenná slučka (nedeľa)
1. Týždenný raport → ktorý kanál predával, čo stál marketing.
2. Metricool štatistiky → ktorý príspevok fungoval.
3. Návrh na budúci týždeň: 1 hlavná téma + príspevky → Lukovo „áno“ → naplánovať.
